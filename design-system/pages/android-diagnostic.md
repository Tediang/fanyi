# Android 诊断页覆盖规则

本页覆盖 `design-system/default/MASTER.md` 中面向 Web/CSS 的部分令牌；未列出的全局颜色、对比度、简洁性和禁用模式仍沿用 Master。

- 使用 Android 系统 sans-serif 与 Material 3 字体层级，确保中文、动态字号和 OEM 字体设置正确回退；不下载或内置仅覆盖拉丁字符的 Outfit/Work Sans。
- 浅色背景使用 `#F7F7F7`、卡片使用 `#FFFFFF` 和 `#E5E5E5` 边框，维持无阴影的紧凑诊断层次；深色模式使用等价的高对比表面。
- 诊断卡使用 `16dp` 圆角和 `18dp` 内边距。它是只读信息表面，不使用 Master 中带 hover/点击语义的 Web 卡片规范。
- 页面只有一个纵向滚动容器，必须应用系统安全区，并在横屏和放大字体下保持所有内容可滚动访问。
- 诊断页无交互按钮、图标、悬停和动画；相应 Web 检查项不适用。
