# Agent Instructions

## Agent skills

### Issue tracker

Issues and specs are tracked as local Markdown under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The tracker uses the canonical triage roles as its status strings. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context project with a root `CONTEXT.md` and system-wide decisions under `docs/adr/`. See `docs/agents/domain.md`.
