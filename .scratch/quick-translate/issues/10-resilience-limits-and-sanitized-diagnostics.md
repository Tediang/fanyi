# 10 — 完成限制、失败恢复与脱敏诊断

**What to build:** 翻译在超长输入、慢服务、流中断和供应商错误下仍保持可理解、可恢复且不泄密；用户能复制足够排查自建服务的脱敏诊断，但文本不会被自动发送到第二个供应商。

**Blocked by:** 06 — 完成翻译会话交互与默认翻译方向; 09 — 完成高级生成参数与受控扩展.

**Status:** resolved

- [x] 每个供应商配置有默认 20,000 Unicode 字符的输入限制，并可调整。
- [x] 超限时在发送前提示缩短文本或调整限制，不产生网络请求、自动拆分或多次计费。
- [x] 连接超时为 10 秒，单次翻译总超时为 60 秒，用户可以主动取消。
- [x] 流中断时保留已收到译文并明确标记不完整；完全失败时保留原文和可操作的重试入口。
- [x] 失败不会自动切换供应商；用户必须明确选择后才向另一个配置发送文本。
- [x] 鉴权、证书、超时、限流、模型不存在和协议解析错误使用不同且简洁的错误类型/文案。
- [x] 可复制诊断包含协议、非敏感 URL 部分、模型、状态码、错误分类和耗时。
- [x] 诊断、普通日志和错误报告均不包含 API Key、敏感请求头、原文、译文或完整请求/响应正文。
- [x] 应用级测试覆盖长度边界、超时、取消、部分流、手动切换和无自动故障转移；安全测试覆盖所有诊断出口。

## Answer

统一网络引擎现在在发请求前执行长度、URL、HTTP 范围和协议能力校验；支持取消、10 秒连接/60 秒总超时、残缺流保留与分类错误。脱敏诊断只包含协议、去查询参数的接口、模型、HTTP 状态、分类和阶段耗时，不含任何文本、秘密或响应正文。
