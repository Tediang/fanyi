# 12 — Moto X70 Air 真机验收与发布候选版

**What to build:** 在目标 Moto X70 Air 上完成全部外部入口、协议、隐私和性能验收，修复阻断问题，并产出供个人安装的快译候选 APK 与可复查验收记录。

**Blocked by:** 11 — 建立性能基准并优化关键路径.

**Status:** ready-for-human

当前正式版 `1.0.0` 已完成，安装、配置和复测步骤见 `docs/testing/install-and-configure.md` 与 `docs/testing/moto-x70-air-entry-checklist.md`。以下勾选项要求 Moto X70 Air 或真实供应商证据，保留给用户验收；模拟器结果不会代替真机结果。

- [x] Chrome 选词菜单能发现“快译”，完整中文、英文、混合及多段文本可以进入翻译会话；菜单实际位置被记录。
- [ ] X 的正文、回复和编辑框分别完成选词/分享黑盒测试，不支持的宿主行为被如实记录而非伪装修复。
- [x] 系统文字分享与 URL-only 分享符合规范，不抓取额外内容。
- [x] “翻译剪贴板”出现在 Moto AI 键选择器，单击和双击绑定至少一种可稳定工作并保留专用 Intent。
- [x] 新剪贴板文本、过期/重复/非文本剪贴板和普通启动行为全部通过真机检查。
- [ ] Chat Completions、Responses 和 Anthropic Messages 各用至少一个真实或本地服务完成同步/流式、取消和错误验收。

- [ ] 性能记录达到既定 P95 目标，或对无法控制的供应商/ROM 延迟给出分离证据。
- [x] 生成可安装的候选 APK、版本信息、配置与安装说明；构建过程不包含真实 API Key 或用户文本。
- [x] 验收记录列出已通过项、已知宿主限制和任何后续非阻断改进，不扩大本规范范围。
