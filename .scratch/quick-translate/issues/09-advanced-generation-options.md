# 09 — 完成高级生成参数与受控扩展

**What to build:** 三种协议的供应商配置都可以使用一致的常用生成选项和受控的厂商扩展，同时明确显示能力差异，防止高级设置破坏核心翻译请求。

**Blocked by:** 07 — 接入 OpenAI Responses 协议; 08 — 接入 Anthropic Messages 协议.

**Status:** ready-for-agent

- [ ] 配置提供推理等级自动、关闭、低、中、高，并由各协议适配器只映射其实际支持的值。
- [ ] 不支持的推理等级或参数在连接测试或请求前明确提示，不会静默显示为已生效。
- [ ] Temperature 和最大输出量默认不发送，只有用户明确设置时才进入请求。
- [ ] 流式默认开启，可按配置关闭；关闭后仍能完成同步翻译。
- [ ] 可配置额外请求头，所有值按敏感数据保存并从诊断中移除。
- [ ] `extra_body` 仅接受 JSON 对象，允许补充厂商字段但禁止覆盖模型、输入/消息、核心提示、鉴权和流式字段。
- [ ] 各协议契约测试证明允许参数正确传递、受保护字段不可覆盖、能力警告准确。
- [ ] 连接测试和实际翻译使用相同的有效配置语义，避免测试成功而正式请求采用不同参数。
