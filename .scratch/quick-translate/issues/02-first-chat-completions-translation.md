# 02 — 打通首个 Chat Completions 翻译闭环

**What to build:** 用户可以配置一个 OpenAI Chat Completions 兼容服务，从手动输入发起一次真实翻译，并在紧凑界面中看到流式纯译文、复制结果并返回。该路径成为后续所有入口和协议共享的首个端到端翻译闭环。

**Blocked by:** 01 — 搭建诊断 App，验证 Android 外部入口.

**Status:** ready-for-agent

- [ ] 用户可以输入配置名称、Base URL、可选 API Key 和模型，API Key 不以明文出现在普通持久化数据或日志中。
- [ ] 手动输入非空文本后可调用 `/v1/chat/completions`，并使用受保护的翻译规则请求纯译文。
- [ ] 同步响应和 SSE 流式响应都能提取译文；流式响应收到首个片段后立即显示。
- [ ] 紧凑界面在网络完成前先显示原文和请求状态。
- [ ] 用户可以显式复制译文；应用不会自动覆盖剪贴板。
- [ ] Back 可关闭紧凑界面并返回先前表面。
- [ ] 可控假服务的应用级测试覆盖请求发出、流式可见结果、完成和基础错误。
- [ ] 协议契约测试验证必需请求字段和代表性 Chat Completions 流事件，不依赖真实凭据。
