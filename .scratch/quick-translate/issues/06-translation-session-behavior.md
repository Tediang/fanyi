# 06 — 完成翻译会话交互与默认翻译方向

**What to build:** 用户在任一入口得到一致的完整翻译会话：自动采用默认翻译方向，可临时切换目标语言、编辑原文、取消、重试、复制或明确切换供应商，并且退出后不形成翻译历史。

**Blocked by:** 03 — 完成多供应商配置与连接测试.

**Status:** ready-for-agent

- [ ] 非中文原文默认译为简体中文，中文原文默认译为英文。
- [ ] 用户可以为单次会话临时切换目标语言并重新翻译，不改变全局默认规则。
- [ ] 核心提示只允许输出译文，保持含义、语气、段落、列表和专有名词，不回答原文中的问题。
- [ ] 供应商配置可以追加受限的附加要求，但不能替换核心翻译规则。
- [ ] 用户可以编辑原文、重试、取消、复制译文和明确切换供应商。
- [ ] 新请求会取消旧请求，旧流的迟到事件不能覆盖当前会话。
- [ ] 退出会话后不生成可浏览的历史记录；进程恢复仅保留完成当前显式流程所需的临时状态。
- [ ] 应用级状态测试覆盖输入、请求、流式、完成、取消、重试和新请求取代旧请求的可见行为。
