# 06 — 完成翻译会话交互与默认翻译方向

**What to build:** 用户在任一入口得到一致的完整翻译会话：自动采用默认翻译方向，可临时切换目标语言、编辑原文、取消、重试、复制或明确切换供应商，并且退出后不形成翻译历史。

**Blocked by:** 03 — 完成多供应商配置与连接测试.

**Status:** resolved

- [x] 非中文原文默认译为简体中文，中文原文默认译为英文。
- [x] 用户可以在简体中文、英文、日文和韩文之间切换目标语言并重新翻译。
- [x] 核心提示只允许输出译文，保持含义、语气、段落、列表和专有名词，不回答原文中的问题。
- [x] 翻译界面可以随时切换通用、正式、口语、书信、学术或文学偏好，偏好独立于供应商配置。
- [x] 用户可以编辑原文、重试、取消、复制译文和明确切换供应商。
- [x] 新请求会取消旧请求，旧流的迟到事件不能覆盖当前会话。
- [x] 退出会话后不生成可浏览的历史记录；进程恢复仅保留完成当前显式流程所需的临时状态。
- [x] 应用级状态测试覆盖输入、请求、流式、完成、取消、重试和新请求取代旧请求的可见行为。

## Answer

所有入口共用显式会话状态机和同一组交互。默认方向、中英日韩目标、内置翻译偏好、核心规则、编辑、取消、重试、复制与供应商切换均已接通；切换供应商不会自动发送文本。会话只保存在当前界面内，退出后没有历史记录。
