# 04 — 打通选词翻译与分享翻译

**What to build:** Chrome 等兼容应用选中的文字以及其他应用分享的文字，可以直接进入当前供应商配置并得到译文；第一次使用尚未配置供应商时，原文会被保留，完成配置后自动继续。

**Blocked by:** 03 — 完成多供应商配置与连接测试.

**Status:** resolved

- [x] `ACTION_PROCESS_TEXT` 收到的完整文本进入翻译会话，诊断入口正式切换为紧凑翻译界面。
- [x] readonly 信息被正确接收，但首版不会尝试替换宿主应用中的原文。
- [x] `ACTION_SEND text/plain` 收到文字时直接进入翻译会话。

- [x] 没有有效供应商配置时保留收到的原文，并引导创建配置；连接测试成功后原翻译继续。

## Answer

选词、分享和 URL-only 入口已统一进入翻译会话；首次配置会保留原文，并只在连接测试成功后继续。`singleTop` 入口与请求序号共同保证新外部输入取代旧请求，迟到结果不会覆盖当前会话。真实 Intent 到假服务的设备测试已覆盖上述路径，Moto/X/Chrome 复测项已追加到真机清单。
