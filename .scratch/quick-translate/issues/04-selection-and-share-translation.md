# 04 — 打通选词翻译与分享翻译

**What to build:** Chrome 等兼容应用选中的文字以及其他应用分享的文字，可以直接进入当前供应商配置并得到译文；第一次使用尚未配置供应商时，原文会被保留，完成配置后自动继续。

**Blocked by:** 03 — 完成多供应商配置与连接测试.

**Status:** ready-for-agent

- [ ] `ACTION_PROCESS_TEXT` 收到的完整文本进入翻译会话，诊断入口正式切换为紧凑翻译界面。
- [ ] readonly 信息被正确接收，但首版不会尝试替换宿主应用中的原文。
- [ ] `ACTION_SEND text/plain` 收到文字时直接进入翻译会话。
- [ ] URL-only 分享只显示 URL 作为输入，不抓取网页、帖子或额外内容。
- [ ] 没有有效供应商配置时保留收到的原文，并引导创建配置；连接测试成功后原翻译继续。
- [ ] 新外部输入到达时，旧翻译不会覆盖新会话的可见结果。
- [ ] 应用级测试从真实 Android Intent 经过当前供应商配置和假服务直到可见译文，覆盖选词、分享、URL-only 和首次配置恢复。
- [ ] 真机验收记录能够分别填写 Chrome 顶层/更多菜单及 X 正文、回复、编辑框的宿主行为。
