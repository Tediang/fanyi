# 03 — 完成多供应商配置与连接测试

**What to build:** 用户可以安全地保存、编辑、删除和切换多个命名供应商配置，并在发送真实翻译前测试连接。云端 HTTPS 服务、无需鉴权的本地服务和经用户明确许可的局域网 HTTP 服务都能以可预测方式配置。

**Blocked by:** 02 — 打通首个 Chat Completions 翻译闭环.

**Status:** ready-for-agent

- [ ] 用户可以管理多个命名供应商配置，并且同一时刻恰有一个当前供应商配置。
- [ ] 配置支持协议类型、Base URL、可选路径覆盖、可选 API Key、模型及可选额外请求头。
- [ ] API Key 与额外请求头值按敏感信息加密保存，列表和编辑页不会意外展示完整秘密。
- [ ] HTTPS 为默认；证书失败不会自动降级到 HTTP。
- [ ] 单个配置可在明确警告后允许局域网明文 HTTP；未选择时 HTTP 请求被拒绝。
- [ ] 连接测试能区分 URL、鉴权、模型和基础协议问题，并且不会写入翻译历史。
- [ ] 删除当前配置后必须明确选择替代配置或进入无当前配置状态，不能静默选择未知目标。
- [ ] 仓库级公开行为测试证明配置重载后仍可鉴权，同时普通存储、诊断和测试输出中不存在明文秘密。
