# 05 — 打通 Moto AI 键快捷键翻译

**What to build:** Moto X70 Air 的 AI 键可以绑定“翻译剪贴板”快捷方式。用户复制文字后触发快捷方式时，新剪贴板文本自动翻译；没有合格文本时直接进入聚焦的手动输入状态。

**Blocked by:** 03 — 完成多供应商配置与连接测试.

**Status:** ready-for-agent

- [ ] “翻译剪贴板”快捷方式使用稳定的专用 Intent，可与普通 launcher 启动明确区分。
- [ ] 只有通过该快捷方式进入时才自动检查剪贴板；应用不存在后台剪贴板监听。
- [ ] 两分钟内写入、类型为文本且未被消费的内容被判定为新剪贴板文本并自动翻译。
- [ ] 过期文本、相同内容的重复消费、空剪贴板和非文本剪贴板不会自动发送给供应商。
- [ ] 没有合格文本时紧凑界面立即显示并聚焦输入框。
- [ ] 普通桌面启动显示手动输入，不自动读取或发送剪贴板。
- [ ] 测试覆盖时间边界、内容指纹、重复保护、非文本和 launcher/shortcut 分流。
- [ ] 真机清单验证快捷方式出现在 Moto 选择器中，单击和双击绑定均保留专用入口，并能通过 Back 返回原应用。
