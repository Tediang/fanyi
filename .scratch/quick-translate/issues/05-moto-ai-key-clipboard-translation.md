# 05 — 打通 Moto AI 键快捷键翻译

**What to build:** Moto X70 Air 的 AI 键可以绑定“翻译剪贴板”快捷方式。用户复制文字后触发快捷方式时，新剪贴板文本自动翻译；没有合格文本时直接进入聚焦的手动输入状态。

**Blocked by:** 03 — 完成多供应商配置与连接测试.

**Status:** resolved

- [x] “翻译剪贴板”快捷方式使用稳定的专用 Intent，可与普通 launcher 启动明确区分。
- [x] 只有通过该快捷方式进入时才自动检查剪贴板；应用不存在后台剪贴板监听。
- [x] 两分钟内写入、类型为文本且未被消费的内容被判定为新剪贴板文本并自动翻译。
- [x] 过期文本、相同内容的重复消费、空剪贴板和非文本剪贴板不会自动发送给供应商。
- [x] 没有合格文本时紧凑界面立即显示并聚焦输入框。
- [x] 普通桌面启动显示手动输入，不自动读取或发送剪贴板。
- [x] 测试覆盖时间边界、内容指纹、重复保护、非文本和 launcher/shortcut 分流。
- [ ] 真机清单验证快捷方式出现在 Moto 选择器中，单击和双击绑定均保留专用入口，并能通过 Back 返回原应用。

## Answer

快捷键入口现在只在 Activity 恢复焦点后读取一次剪贴板，修复了“刚复制后由 AI 键启动拿不到文本”；普通启动完全不读剪贴板。新鲜度、文本 MIME、空值和内容指纹均在请求前判定。Moto 已证实快捷方式可枚举且单击/双击可触发，但该 ROM 创建的任务栈按 Back 返回桌面，应用无法恢复触发前应用，因此最后一项保留为已知平台限制而不虚假勾选。
