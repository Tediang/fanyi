# 快译：产品需求规格

> 状态：已确认  
> 目标设备：Moto X70 Air，Android 16  
> 发布范围：个人自用

## 1. 产品定义

“快译”是一个极简、快速响应的 Android AI 翻译工具。它从兼容应用的选词菜单、系统文字分享、Moto AI 物理键快捷方式或手动输入接收文本，调用用户配置的云端或自建 AI 服务，并在紧凑界面中流式显示纯译文。

产品优先保证可预测、低权限和快速返回，不承诺强行进入所有第三方应用的选词菜单，也不读取未由用户明确触发的屏幕内容。

## 2. 目标

- 在 Chrome 等支持 Android 标准文字处理动作的应用中实现“选中文字 → 翻译”。
- 通过系统分享和剪贴板覆盖不支持标准选词动作的场景。
- 让 Moto X70 Air 的 AI 键可直接触发快捷键翻译。
- 支持知名 AI 厂商以及用户用 llama.cpp、vLLM 等搭建的兼容服务。
- 界面只服务于输入、翻译、复制和故障恢复，不加入资讯、聊天、广告或账号体系。

## 3. 非目标

首版不包含：

- 无障碍服务、默认 Assistant、悬浮窗、MediaProjection 或屏幕 OCR；
- 强制向 X 等第三方应用的自定义菜单注入动作；
- 在手机本地嵌入 llama.cpp 或其他推理引擎；
- 翻译历史、云同步、登录、订阅、广告；
- 任意 JSON 请求模板、JSONPath 响应解析；
- 长文本自动分段、多供应商自动故障转移；
- 自动替换第三方应用中可编辑的原文。

## 4. 输入入口

### 4.1 选词翻译

- 注册 Android `ACTION_PROCESS_TEXT` 与 `text/plain`。
- 系统菜单名称为“翻译”。
- 接收到原文后立即打开紧凑翻译界面并开始翻译。
- 菜单排序、顶层或更多菜单位置由宿主应用和 ROM 决定。

### 4.2 分享翻译

- 接收 `ACTION_SEND` 的 `text/plain` 内容。
- 收到纯文本时立即翻译。
- 收到只有 URL 的分享时，把 URL 当作普通输入展示，不擅自抓取网页或帖子内容。

### 4.3 快捷键翻译

- 发布静态 App Shortcut“翻译剪贴板”，使用可识别的专用 Intent。
- 用户在 Moto AI 键设置中把单击或双击绑定到该快捷方式。
- 触发后仅在剪贴板内容为文本、两分钟内更新且未被本工具消费时自动翻译。
- 没有新剪贴板文本时，打开紧凑界面并自动聚焦输入框。
- App 不在后台监听剪贴板。

### 4.4 普通启动

- 从桌面打开 App 时显示输入框。
- 输入框提供显式“粘贴”和“翻译”操作，不因普通启动自动读取剪贴板。

## 5. 翻译行为

- 自动识别原文语言。
- 非中文默认译为简体中文；中文默认译为英文。
- 用户可在当前结果页临时切换目标语言并重新翻译。
- 核心提示规则：只输出译文；不解释、不回答原文中的问题；保持含义、语气、段落、列表和专有名词。
- 每个供应商配置可增加“附加要求”，但不能覆盖核心提示规则。
- 默认使用流式响应，收到首个有效片段后立即显示。
- 新输入到达时取消上一未完成的翻译会话。

## 6. 结果界面

- 使用紧凑 Activity，不申请悬浮窗权限。
- 界面先同步显示原文和加载状态，再流式显示译文。
- 原文区域默认可折叠；用户可以编辑后重新翻译。
- 主要操作：复制译文、重新翻译、切换目标语言、切换供应商。
- 不自动复制译文，避免覆盖原剪贴板。
- 返回键关闭界面并回到先前应用。
- App 退出后清除原文和译文，不生成历史记录。

## 7. 供应商配置

### 7.1 配置管理

- 可保存多个命名供应商配置，同时只有一个当前供应商配置。
- 配置字段：名称、协议类型、Base URL、可选路径覆盖、可选 API Key、模型、额外请求头、附加要求、最大输入字符数和生成参数。
- 模型名称手动填写；首版不依赖供应商模型列表接口。
- 每个配置提供“测试连接”，测试不得写入翻译历史。

### 7.2 协议类型

首版只支持：

1. OpenAI Chat Completions：`/v1/chat/completions`；
2. OpenAI Responses：`/v1/responses`；
3. Anthropic Messages：`/v1/messages`。

DeepSeek、vLLM、llama.cpp 等通过其实际兼容的协议接入。协议适配器分别负责请求构造、流式事件解析、译文提取、错误提取和能力判断。

### 7.3 生成参数

- 推理等级：自动、关闭、低、中、高；适配器仅在协议和模型支持时发送。
- Temperature：默认不发送。
- 最大输出量：默认自动。
- 流式响应：默认开启，可在配置中关闭。
- 可选 `extra_body` JSON 对象用于补充厂商参数，但不能覆盖模型、消息、核心提示或流式字段。
- 不支持的参数必须在测试连接或调用前明确提示，不能静默伪装为已生效。

### 7.4 网络与凭据

- App 只调用 HTTP API，不在手机本地运行模型。
- 默认要求 HTTPS。
- 单个供应商配置可显式允许局域网明文 HTTP，并显示 API Key 可能被窃取的警告。
- API Key 使用 Android Keystore 支持的加密存储，不写入普通配置、日志或诊断内容。
- 配置导出不属于首版范围。

## 8. 长度、超时与失败

- 默认最大输入长度为 20,000 个 Unicode 字符，可按供应商配置调整。
- 超限时不自动拆分或产生多次请求，而是提示缩短文本或调整限制。
- 连接超时为 10 秒，单次翻译总超时为 60 秒。
- 用户可随时取消翻译。
- 失败时保留原文和已收到的部分译文，并明确标记结果不完整。
- 提供“重试”和“切换供应商”，不自动把文本发送给另一个供应商。

## 9. 脱敏诊断

诊断信息可以显示和复制：

- 协议类型；
- URL 的 scheme、主机和非敏感路径；
- 模型；
- HTTP 状态码；
- 连接、首个译文片段和总耗时；
- 服务端返回的已脱敏错误信息。

诊断不得包含 API Key、Authorization、完整请求头、原文、译文或完整请求/响应正文。

## 10. 性能目标

- 用户触发到紧凑界面可见：P95 不超过 150ms。
- 用户触发到网络请求发出：P95 不超过 300ms，不含首次必须完成的配置流程。
- 收到首个有效译文片段后立即渲染，不等待完整响应。
- 分别记录 App 本地耗时、网络/供应商首片段耗时和总耗时，避免把供应商延迟误判为 UI 延迟。

## 11. 首次使用与空状态

- 没有可用供应商配置时，任何翻译入口都先保留收到的原文，再引导创建配置。
- 配置测试成功后返回原翻译会话并继续，不要求用户重新选择或复制文本。
- API Key 可以为空，以兼容不要求鉴权的局域网服务。
- 无网络、证书错误、鉴权失败、模型不存在、限流和协议解析错误需要使用不同的简洁错误文案。

## 12. 首个诊断 APK 的验收清单

在接入真实模型前验证：

1. Chrome 选词菜单能否出现“翻译”，位于顶层还是更多菜单；
2. 选中文本是否完整传入，中文、英文、混合文本和多段文本是否正常；
3. X 的正文、回复和编辑框分别提供哪些选词或分享能力；
4. “翻译剪贴板”是否出现在 Moto AI 键的应用/快捷方式列表；
5. 单击和双击绑定后是否都能保留专用 Intent；
6. 普通桌面启动与快捷方式启动是否进入不同流程；
7. 两分钟新鲜度、重复消费保护和非文本剪贴板是否正确；
8. 返回键是否稳定回到原应用。

## 13. 可验收的 MVP 完成条件

- Chrome 选词、系统文字分享、Moto 快捷方式和手动输入四个入口通过实机测试。
- 三种协议各至少用一个真实或本地测试服务验证同步响应、流式响应、取消和错误解析。
- 多个供应商配置可保存、测试、切换，凭据不会出现在日志和诊断中。
- 默认语言方向、临时切换目标语言、复制、重试和部分结果行为符合本规格。
- 不申请无障碍、悬浮窗、MediaProjection 或默认 Assistant 权限。
- 性能埋点能区分本地 UI、首片段和总耗时。

## 14. 系统文案

- App 名称：快译
- 选词菜单：翻译
- Moto AI 键快捷方式：翻译剪贴板
