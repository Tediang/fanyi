# Moto X70 Air 外部入口实测清单

目标设备：Moto X70 Air，Android 16。下列已勾选结果是 `0.1.0-diagnostic` 的平台能力基线，保留用户原始实测记录。`0.4.0-rc1` 已把所有入口接入统一翻译会话，需要按文末“候选版复测”再次验收真实翻译行为。

## 准备

- [x] 安装 `app/build/outputs/apk/debug/app-debug.apk`。
- [x] 在系统应用列表中确认名称为“快译”。
- [x] 打开“快译”，确认显示“普通启动”和“未收到外部文本”。
- [x] 确认系统未要求无障碍、悬浮窗、屏幕捕获或默认 Assistant 权限。

## Chrome 选词

1. 在 Chrome 网页中长按并选中一段可复制文字。
2. 检查第一层菜单；如果未出现，打开右侧更多菜单。
3. 点击“快译”。

- [x] “快译”的位置：更多菜单。
- [x] 快译显示入口“选词翻译”。
- [x] 收到的文本与完整选区一致。
- [x] Action 为 `android.intent.action.PROCESS_TEXT`。
- [x] MIME 为 `text/plain`。
- [x] 返回键能回到原 Chrome 页面和原滚动位置。

备注：

> 菜单位置由 Chrome 和系统决定；快译只能声明入口，不能强制固定在第一层。

## X 的不同文字表面

分别测试正文、回复和编辑器中的可选文字。若某一表面没有“快译”，再测试系统“分享”是否能找到快译。

本次已确认：X 内未显示可调用快译的选词菜单；系统分享目标能找到快译，但 X 只发送帖子 URL，没有发送正文。以下各文字表面是否一致仍可继续细分记录。

预期边界：X 若没有暴露标准文字选择或 `ACTION_PROCESS_TEXT`，普通应用无法强行把“快译”注入该菜单；文本分享是低权限回退入口。

## 系统文字分享

- [x] 分享一段普通文字时，系统分享目标中能找到“快译”。
- [x] 打开后显示“分享翻译”和“文字”。
- [x] 分享一个仅包含 `http://` 或 `https://` 地址的项目。
- [x] 打开后显示“分享翻译”和“URL（不会抓取）”。
- [x] 页面只显示收到的 URL，没有抓取网页内容。

## Moto AI 键快捷方式

1. 打开“设置 → 快捷键 → 单击”或“双击”。
2. 选择“启动应用”，找到“快译”。
3. 打开快译的子操作，检查是否出现“翻译剪贴板”。
4. 将单击或双击绑定到该子操作，而不是仅绑定普通 App 启动。

- [x] 快捷方式选择器能枚举“翻译剪贴板”。
- [x] 单击绑定结果：成功
- [x] 双击绑定结果：成功
- [x] 触发后显示“快捷键翻译”和专用 Action。
- [x] 触发后显示“诊断版未读取剪贴板”；此阶段不会发送任何文本。
- [x] 返回行为已记录：回到桌面，而不是触发前的应用。

记录 Moto 系统版本/补丁日期和任何一次失效后的重启、重新绑定情况：

> Moto 的“启动应用”快捷方式按 Launcher/App Shortcut 任务启动；专用入口和单击/双击均正常，但返回栈不保留触发前应用。

## 结论记录

- Chrome 入口：通过
- X 入口：有限制——无选词菜单；分享只提供 URL，不提供正文。
- 系统分享：通过——快译正确处理宿主实际提供的文字或 URL；不会补抓正文。
- Moto AI 键：有限制——专用快捷方式可枚举和触发，但返回键回到桌面。
- 是否可进入下一张“统一输入路由”票：是
- 阻塞问题：无；X 正文获取和 Moto 返回栈是已确认的平台/ROM 边界。

## `0.4.0-rc1` 候选版复测

安装与配置见 `docs/testing/install-and-configure.md`。以下项目必须在新 APK 上重新测试，不能沿用诊断版的界面结果。

- [ ] 普通启动不会自动读取剪贴板；手动输入、粘贴、翻译、取消、重试、复制均正常。
- [ ] Chrome 选词后显示完整原文并自动翻译；中文、英文、混合、多段各测一次。
- [ ] `readonly` 选词能翻译，但不会尝试替换 Chrome 原文。
- [ ] 普通文字分享自动翻译；URL-only 分享不抓取网页或 X 帖子正文。
- [ ] 未配置供应商时，外部原文在新增配置过程中保持；“测试连接”成功后自动继续。
- [ ] 复制新文字后触发“翻译剪贴板”能自动翻译，不再出现拿不到刚复制文本的问题。
- [ ] 相同文本第二次触发、超过两分钟的文本、空或非文本剪贴板均进入手动输入，不自动请求。
- [ ] Chat Completions 使用 DeepSeek 或其他真实服务完成流式翻译，结果不再出现 `nullnull…`。
- [ ] Responses 和 Anthropic Messages 各用可用服务完成至少一次同步或流式翻译。
- [ ] 401、模型错误、超时和流中断分别显示可理解错误；部分流保留已经收到的译文。
- [ ] “复制脱敏诊断”不包含 API Key、自定义敏感请求头、原文或译文。
- [ ] 返回行为复核并记录：Chrome/分享入口返回宿主；Moto AI 键入口预计仍由 ROM 返回桌面。
- [ ] 按 `docs/testing/performance-baseline.md` 的口径各采集至少 20 个真机样本，并追加原始值。
