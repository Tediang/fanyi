# Moto X70 Air 外部入口实测清单

目标设备：Moto X70 Air，Android 16。测试对象是“快译”诊断版；它只显示入口信息，不读取剪贴板、不联网、不调用模型。

## 准备

- [ ] 安装 `app/build/outputs/apk/debug/app-debug.apk`。
- [ ] 在系统应用列表中确认名称为“快译”。
- [ ] 打开“快译”，确认显示“普通启动”和“未收到外部文本”。
- [ ] 确认系统未要求无障碍、悬浮窗、屏幕捕获或默认 Assistant 权限。

## Chrome 选词

1. 在 Chrome 网页中长按并选中一段可复制文字。
2. 检查第一层菜单；如果未出现，打开右侧更多菜单。
3. 点击“翻译”。

- [ ] “翻译”的位置：`第一层 / 更多菜单 / 未出现`
- [ ] 快译显示入口“选词翻译”。
- [ ] 收到的文本与完整选区一致。
- [ ] Action 为 `android.intent.action.PROCESS_TEXT`。
- [ ] MIME 为 `text/plain`。
- [ ] 返回键能回到原 Chrome 页面和原滚动位置。

备注：

> 菜单位置由 Chrome 和系统决定；快译只能声明入口，不能强制固定在第一层。

分别测试正文、回复和编辑器中的可选文字。若某一表面没有“翻译”，再测试系统“分享”是否能找到快译。

预期边界：X 若没有暴露标准文字选择或 `ACTION_PROCESS_TEXT`，普通应用无法强行把“翻译”注入该菜单；文本分享是低权限回退入口。

## 系统文字分享

- [ ] 分享一段普通文字时，系统分享目标中能找到“快译”。
- [ ] 打开后显示“分享翻译”和“文字”。
- [ ] 分享一个仅包含 `http://` 或 `https://` 地址的项目。
- [ ] 打开后显示“分享翻译”和“URL（不会抓取）”。
- [ ] 页面只显示收到的 URL，没有抓取网页内容。

## Moto AI 键快捷方式

1. 打开“设置 → 快捷键 → 单击”或“双击”。
2. 选择“启动应用”，找到“快译”。
3. 打开快译的子操作，检查是否出现“翻译剪贴板”。
4. 将单击或双击绑定到该子操作，而不是仅绑定普通 App 启动。

- [ ] 快捷方式选择器能枚举“翻译剪贴板”。
- [ ] 单击绑定结果：`成功 / 未出现 / 启动了普通入口 / 其他`
- [ ] 双击绑定结果：`成功 / 未出现 / 启动了普通入口 / 其他`
- [ ] 触发后显示“快捷键翻译”和专用 Action。
- [ ] 触发后显示“诊断版未读取剪贴板”；此阶段不会发送任何文本。
- [ ] 返回键能回到触发前的应用。
