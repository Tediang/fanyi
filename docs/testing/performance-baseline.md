# 快译性能基线

记录日期：2026-08-24  
候选版本：`0.4.0-rc1`  
测试环境：`pintu-api37-phone` Android API 37 模拟器，本机确定性 `MockWebServer`，不经过互联网。

这些数字用于发现 App 自身的性能回归，不代表 Moto X70 Air 真机验收。模拟器、调试构建、测试框架和首次 JIT 都会引入额外开销。

## 暖入口基准

每个入口 10 次。计时从 `MainActivity` 接收入口开始，到 Compose 首帧提交；选词入口同时记录请求发出、首个有效译文片段和完成耗时。

| 指标 | 原始样本（ms） | P95 |
| --- | --- | ---: |
| 普通启动 → 界面可见 | 251, 287, 337, 309, 287, 323, 276, 281, 337, 262 | 337 ms |
| 选词入口 → 界面可见 | 350, 282, 316, 343, 341, 324, 312, 341, 355, 322 | 355 ms |
| 快捷键入口 → 界面可见 | 368, 501, 385, 362, 372, 578, 409, 309, 510, 452 | 578 ms |
| 选词入口 → 请求发出 | 284, 235, 271, 288, 267, 279, 264, 255, 301, 270 | 301 ms |
| 请求开始 → 首个有效片段 | 31, 19, 30, 34, 61, 28, 32, 39, 39, 41 | 61 ms |
| 请求开始 → 完成 | 32, 19, 30, 34, 61, 28, 32, 39, 42, 41 | 61 ms |

基准由 `LaunchPerformanceBenchmarkTest` 自动生成。测试会验证三个入口均有完整样本，并将原始值写入设备测试日志。性能记录只保留入口和时长，最多 100 条，仅存在于当前进程内，不包含原文、译文、密钥、请求头或响应正文。

## 尚待真机验收

- Moto X70 Air 上各入口到界面可见的 P95 目标：不超过 150 ms。
- 已有有效配置时，入口到请求发出的 P95 目标：不超过 300 ms。
- 真机测量需区分 App 本地耗时、网络到首片段耗时和供应商总耗时。

当前模拟器诊断未达到产品真机目标，不能据此宣称达标；也不能把供应商网络延迟归入 App 本地耗时。真机结果应追加到本文并保留原始样本。
